# Labradorite Drift

Full-colour Python 3 neon asteroids arcade for [ElbowOS](https://x.com/ElbowOS).

Steer a teal shard through an indigo trench. Split blue rocks into violet chips. Scoop magenta cores. A / D aim. W thrust. Space fire.

## Play

```
pip install -r requirements.txt
python3 labradorite_drift.py --play
```

## Record a 9:16 reel

```
python3 labradorite_drift.py --record
```
